# Cardable

A retro multiplayer sandbox card table: the software deals, the players
enforce the rules. Server-as-dealer hidden state, customizable named
stacks, physical on-table dice, a built-in 52-card deck, personal card
libraries with image intake, and key-phrase action links in card text.

See **BUILD-NOTES.md** for what v0.1 includes, what is stubbed, and how to
run it (Docker / Portainer, port 8901).
